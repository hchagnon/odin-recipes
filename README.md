# odin-recipes
Project: Recipes
Technologies Used: HTML
Contact Information: hchagnon.dev@gmail.com

The purpose of this project is to exercise HTML knowledge learned up to this point in The Odin Project Foundations course. I have built a basic recipie website using exclusively HTML elements (CSS will come later), along with some free-to-use sample images for each recipe. 

Of particular interest to me in this project was the use of absolute and relative links and accessing files within the same, or parent directories. I also found interest in how the file structure of the project is to be set up and used throught the documents.
